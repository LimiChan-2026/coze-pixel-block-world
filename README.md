# COZE 像素方块世界

基于 Three.js、TypeScript 和 Vite 制作的 WebGL 3D 方块沙盒游戏 Demo。项目按开发计划书拆分为世界、玩家、交互、背包、生物、天气和渲染模块；打开后会在中央沙地出生点前方看到由方块搭建的 `COZE` 地标。

## 已实现

- 第一人称镜头、WASD 移动、鼠标视角、跳跃、冲刺与体素碰撞
- 程序化起伏地形、草地/泥土/石头/沙地、树木以及出生点保护
- 方块射线拾取：左键放置、右键破坏与资源回收
- 快捷栏、生命/饥饿/经验数据，以及高处坠落伤害
- 昼夜循环、可用 `R` 切换的雨天、远处游荡的生物与夜间追击生物
- 自适应 HUD，以及手机浏览器的虚拟摇杆、视角滑动、放置/破坏/跳跃按钮
- 隐藏面剔除与可见面合并渲染、体素网格射线拾取、自适应分辨率；数据结构按 Chunk 保留

## 启动

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

终端会输出本地地址，通常是 `http://localhost:5173`。生产构建：

```bash
npm run build
npm run preview
```

`npm run build` 会在 `dist/` 生成可部署的静态文件，可部署到 GitHub Pages、Vercel、Netlify 或任意静态站点服务器。

## 操作

| 操作 | 桌面端 | 移动端 |
| --- | --- | --- |
| 移动 | `W` `A` `S` `D` | 左侧虚拟摇杆 |
| 转向 | 鼠标 | 右侧屏幕滑动 |
| 跳跃 | 空格 | 跳跃按钮 |
| 冲刺 | Shift | — |
| 放置 | 左键 | 放置按钮 |
| 破坏 | 右键 | 破坏按钮 |
| 选择方块 | 数字 `1`–`5` 或快捷栏 | 快捷栏 |
| 雨天 | `R` | 外接键盘 `R` |

按 `Esc` 释放桌面端鼠标指针，再点击“进入世界”可继续探索。

## 目录

```text
src/
  game/
    Block.ts       方块定义
    Chunk.ts       区块数据
    World.ts       生成、体素数据、实例化网格、射线交互
    Player.ts      第一人称控制与碰撞
    Inventory.ts   快捷栏与生存属性
    Entity.ts      生物行为
    Weather.ts     昼夜与降雨
    Renderer.ts    Three.js 渲染器
  components/Hud.ts  游戏界面与移动端触控
  main.ts            游戏编排与主循环
```
